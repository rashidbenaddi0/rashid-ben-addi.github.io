رشيد بن عدي — موقع الكاتب
===========================

ملفات الموقع:
- index.html : محتوى الموقع
- style.css  : التصميم المتجاوب
- script.js  : تفاعلات القائمة وتغيير الواجهة

طريقة المعاينة:
1. فك ضغط الملف.
2. افتح index.html في متصفحك.

قبل النشر:
- استبدل YOUR_EMAIL@example.com ببريدك الحقيقي.
- أضف روابط حساباتك الحقيقية.
- استبدل نماذج الأغلفة المؤقتة بصور أغلفتك الأصلية.
- راجع العبارات التجريبية في قسم «من الكتابة» واستبدلها بنصوصك الأصلية.
- زر EN يبدل اتجاه الواجهة وتسميات القائمة فقط حاليًا؛ محتوى الصفحة ما زال بالعربية.

النشر المجاني باستخدام GitHub Pages:
1. أنشئ حسابًا مجانيًا في https://github.com إذا لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا باسم rashid-ben-addi.github.io (إذا كان الاسم متاحًا لحسابك).
3. ارفع الملفات الثلاثة index.html وstyle.css وscript.js إلى المستودع.
4. افتح Settings ثم Pages.
5. اختر النشر من الفرع main والمجلد /(root)، ثم Save.
6. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة Pages.

قد يستغرق النشر بضع دقائق. الرابط النهائي يعتمد على اسم حساب GitHub المتاح لديك.
